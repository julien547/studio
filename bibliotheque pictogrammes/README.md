# Bibliothèque de pictogrammes SAI

Déposer ici la bibliothèque **Légende SAI.cclibs** et son inventaire JSON, ou le contenu extrait de l’archive en conservant strictement les noms et sous-dossiers d’origine. Git ne conserve pas les dossiers vides : ce fichier matérialise le dossier.

L’importeur du module `releves` vérifiera le manifeste, les identifiants stables et les ressources AI avant de les autoriser pour le placement Illustrator. L’inventaire seul ne remplace pas les fichiers vectoriels. Ne pas transformer les AI en PNG et ne pas renommer les UUID.

L’interface web de GitHub limite les fichiers envoyés par navigateur à 25 Mio. Pour une archive plus volumineuse, utiliser Git ou Git LFS ; au-delà de 100 Mio, GitHub impose Git LFS. On peut aussi déposer les fichiers extraits individuellement (sans les modifier), puis importer une archive ZIP reconstruite depuis ce contenu.

Ces ressources sont privées et ne doivent pas être copiées dans la racine publique du site. Ne déposer ni relevés clients, ni BAT, ni secrets dans ce dossier.
