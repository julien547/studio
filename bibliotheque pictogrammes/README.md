# Bibliothèque de pictogrammes — Légende SAI

Bibliothèque Creative Cloud (`Légende SAI.cclibs`, 178 Mo), fournie en deux parties
car GitHub refuse les fichiers de plus de 100 Mo.

## Reconstituer le fichier

```sh
cat Legende-SAI.cclibs.part-* > "Légende SAI.cclibs"
shasum -a 256 "Légende SAI.cclibs"
```
